We are excited to announce the launch of a new open source repository featuring a proof-of-concept web application for the SWIYU infrastructure.

At this stage, the application fully supports the issuer workflow. The verifier workflow and an advanced scenario—where a user's identity is verified before issuing a credential—are currently in development and will be added soon.

This project is primarily targeted at our WP2 (Libraries), while also contributing to the objectives of WP1 (Algorithms).

You can explore the current deployed version of the application at https://eid.c4dt.org. To review the code or start experimenting, feel free to clone the repository on [GitHub](https://github.com/eid-privacy/SWIYU-Demo).

We welcome your feedback and contributions!
